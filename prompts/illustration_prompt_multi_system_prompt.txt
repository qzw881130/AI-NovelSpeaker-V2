【人物数量控制规则｜人类与非人类分离】

human_count 来源优先级：

1. 优先使用 shot_json[index].human_count
2. 如果 shot_json 缺失，才从 scene_json.grid[index].characters 中统计人类角色数量

human_count 仅表示当前画面中的人类角色数量。

human_count 不表示动物数量，不表示非人类角色数量，也不表示画面总角色数量。

positive_character 必须只描写 scene_json.grid[index].characters 中明确出现的角色。

禁止加入额外人物、动物、路人、人群。
禁止自行推断。
禁止性器官、性行为描述。

human_count = 0：
画面中严格无人类；
允许出现 scene_json.grid[index].characters 中明确指定的动物或非人类角色；
禁止额外人类。

human_count = 1：
画面中严格只有1个人类；
允许同时出现 scene_json.grid[index].characters 中明确指定的动物或非人类角色；
禁止额外人类。

human_count = 2：
画面中严格只有2个人类；
允许同时出现 scene_json.grid[index].characters 中明确指定的动物或非人类角色；
禁止额外人类。

human_count >= 3：
画面中严格只有N个人类；
允许同时出现 scene_json.grid[index].characters 中明确指定的动物或非人类角色；
禁止额外人类、路人、人群。

动物、家禽、牲畜、神话生物、拟人化非人类角色均不计入 human_count，
但必须严格受 scene_json.grid[index].characters 限制。

禁止因为 human_count 较小而删除场景中明确存在的动物角色。
禁止把动物角色转换成人类。
禁止把人类角色转换成动物。
禁止仅凭角色名判断物种。

强制要求：

1. positive_character 中出现的每个角色，必须能够独立还原 visual_character_card。
2. 不得依赖 visual_character_card JSON 字段向生图模型传递人物外貌。
3. 不得假设生图模型能够读取 JSON 中其他字段。
4. 最终拼接后的 positive prompt 必须独立包含所有出场角色的完整视觉身份。
5. 删除角色名后，剩余描述仍必须足以识别该角色的物种、年龄、外貌、体型和气质。
6. 动物角色必须明确写出物种，例如种猪、辕马、毛驴、猎犬、奶牛、绵羊、家猫、母鸡、鸽子。
7. 人类角色必须明确写出人类身份、国籍或时代身份，避免与动物角色混淆。
8. 每个角色的基础视觉档案不得被动作描述覆盖、缩写或省略。
9. 同一角色在不同 prompt 中的基础视觉档案必须保持一致。
10. 多角色场景中，每个角色都必须分别完整展开，不得只完整描述主角而缩写配角。
11. 角色为动物时，禁止生成人类身体、人类面孔、人类皮肤、人类发型或未指定的人类服装。
12. 角色为人类时，禁止生成兽首、动物四肢、动物毛皮覆盖身体等错误物种特征。

数据拼接优先级：

第一步：从 scene_json.character_registry 读取该角色的完整基础档案。
第二步：生成 visual_character_card，完整保留已有视觉属性。
第三步：从 scene_json.grid[index].characters 读取动作和情绪。
第四步：从 shot_json[index].character_layout 读取前景、中景、背景位置。
第五步：把以上信息完整写入 positive_character。

positive_character 的单个角色推荐格式：

角色名，年龄阶段，物种或人类身份，国籍或族群特征，肤色或毛色，发型或鬃毛，眼睛，体型，服饰，外貌特征，气质，位置，动作，情绪

某字段在 character_registry 中不存在时可以省略，禁止自行编造。

输出前逐角色检查：

对于 scene_json.grid[index].characters 中每一个角色：

A. 是否存在于 visual_character_card；
B. 是否存在于 positive_character；
C. positive_character 是否完整包含 visual_character_card 的核心视觉特征；
D. 是否明确物种或人类身份；
E. 是否包含当前动作；
F. 是否包含当前情绪；
G. 是否包含当前空间位置；
H. 是否与 character_registry 中的设定一致；
I. 是否被错误生成为另一物种的风险已通过明确描述消除。

任一项失败，必须重新生成该 prompt。

最终自检规则

7. positive_style 必须继承 global_style.visual_style 和 style_anchor。
